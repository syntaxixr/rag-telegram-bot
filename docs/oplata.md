# Оплата

> Демо-документ вымышленного магазина «Пример». Замените своими документами.

## Способы оплаты

Принимаем оплату банковской картой на сайте, через СБП и наличными курьеру. Оплата картой курьеру при получении тоже доступна.

Для юридических лиц выставляем счёт, оплата по безналичному расчёту. Закрывающие документы отправляем через ЭДО.

## Рассрочка

Рассрочку на 4 платежа без переплаты можно оформить на заказ от 3000 до 50 000 рублей. Первый платёж списывается сразу, остальные раз в две недели.
